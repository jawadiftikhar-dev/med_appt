# Medical Appointment Booking

A front-end web application for booking medical appointments online.  
This project is part of the IBM Front-End Developer Capstone.

## Project Structure
- `Landing/` – Contains the prototype landing page (`LandingPage.html` and `LandingPage.css`).
- Additional React components will be added in later modules.

## Getting Started
1. Clone the repository.
2. Open `Landing/LandingPage.html` in a browser to view the prototype.

## Notes
- The landing page layout will be customised to match the StayHealthy medical booking theme.
- Future exercises will convert this static prototype into a dynamic React application.
